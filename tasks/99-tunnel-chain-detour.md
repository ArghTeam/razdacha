## TLDR
Правило может указать второе звено — WARP — второй выпадашкой в модалке («VLESS → WARP»).
Пара материализуется клоном WARP-эндпоинта с `detour`, одинаковые пары схлопываются.
Экран туннелей не меняется. Требует ADR.

## Goal
Дать правилу выход «ВПН + WARP», не заводя дублей туннелей в инвентаре.

## Domains touched
- [store](../context/store/) — второе звено у правила, миграция
- [singbox](../context/singbox/) — тег пары, `detour`, дедупликация
- [api](../context/api/) — проверка, что второе звено — WARP
- [ui](../context/ui/) — вторая выпадашка в модалке правила, только WARP-туннели

## Decisions
- 2026-07-27 — цепь вешается на правило, а не на туннель: иначе «просто WARP» и
  «VLESS → WARP» требуют двух записей WARP в инвентаре, и из правила не видно,
  сколько за именем прыжков.
- 2026-07-27 — `detour` у sing-box принадлежит outbound, поэтому цепь не выражается
  одним route-правилом: на каждую различную пару генерируется свой outbound с тегом,
  дедупликация по паре.
- 2026-07-27 — [ADR 0012](../docs/decisions/0012-tunnel-chain-detour.md): цепь — ровно два
  звена, второе всегда WARP и оно необязательное. Первым звеном годится любой туннель,
  включая пул. Обратное направление «WARP → обычный туннель» запрещено по смыслу, а не
  технически: WireGuard-эндпоинт носителем `detour` быть может, но WARP — способ выйти в
  интернет чужим лицом, поэтому он последний.
- 2026-07-27 — валидация: второе звено обязано быть WARP. Запрета на повтор туннеля не
  нужно — звенья разного класса по построению.
- 2026-07-27 — вопрос «допустим ли пул не первым звеном» снят сужением, а не отказом:
  вторым звеном может быть только WARP, поэтому «VLESS → пул» невыразим. «Пул → WARP»
  работает: `detour` резолвится в сам объект группы, а участника группа выбирает на каждом
  дозвоне — ротация цепь переживает, конфиг не меняется.
- 2026-07-27 — ADR отдельным PR до кода: решение должно читаться без диффа реализации.

## Acceptance criteria
- [ ] в правиле указывается второе звено — WARP, в конфиге появляется клон с `detour`
- [ ] правило без второго звена работает как раньше, `detour` в конфиге не появляется
- [ ] две одинаковые пары в разных правилах дают один outbound
- [ ] второе звено не-WARP отклоняется на русском до `sing-box check`
- [ ] вторая выпадашка в модалке показывает только WARP-туннели
- [ ] на стенде: список A выходит с адреса Cloudflare через наш VLESS, список B — с адреса VLESS
- [ ] ADR принят, на него ссылается инвариант слоя singbox
