# 181 — единый общий пул вместо 7 страновых

Issue: #181. Заменяет ADR 0017 новым ADR 0018.

## Цель

Убрать 7 встроенных страновых пулов (NL/DE/US/FR/GB/FI/KZ) и вернуть **один встроенный
общий пул**, который ротирует бесплатные ключи всех стран из источника igareck. Оператор
вешает на него конкретных клиентов **существующими правилами по пирам** (`peer_scope`),
чтобы не пускать сторонних клиентов на ручные (личные) туннели.

Это возврат к модели единого пула (близко к ADR 0015), но источник — igareck по всем
странам. geo-IP-разбивка, введённая ADR 0017, становится не нужна.

## Контекст и что менять

Задача во многом откатывает работу #167 (страновые туннели) к единому пулу, **сохраняя
источник igareck**. Ключевые места (проверить preflight'ом, строки могли сместиться):

- **store**
  - `internal/store/model.go` — убрать `countryPools`, `CountryPools()`, `PoolName()`,
    `flagEmoji()`, тип `Country`, поле `Tunnel.Country` (или оставить как no-op, если
    дёшево для отображения — по решению исполнителя, но без партиционирования).
  - `internal/store/tunnels.go` — `EnsureBuiltinCountryPools` → `EnsureBuiltinPool`
    (один встроенный пул `builtin=1`, `pool`, `enabled=0`, `source=pool`,
    `CatalogURL` igareck). Сохранить `detachRulesFromTunnel`/`ruleRefsForTunnel` для
    миграции. `removeLegacyBuiltinPools` расширить: свернуть 7 страновых в один.
  - `internal/store/migrate.go` — новая миграция: свернуть существующие 7 страновых
    пулов в один общий; правила, ссылавшиеся на страновой пул, **отвязать по ADR 0013**
    (primary `tunnel_id`→NULL + выключить правило; via-only `via_tunnel_id`→NULL,
    правило оставить). Столбец `country` можно оставить в схеме (не удаляем колонки в
    SQLite без нужды), просто перестать использовать.
- **lists**
  - `internal/lists/pool.go` — `Refresh`: убрать группировку по стране и
    `poolServersForCountry`/фильтр по стране; наполнять один пул **всеми** серверами
    из источника (fetch один раз, применить целиком).
  - `internal/lists/pool_igareck.go` — убрать geo-IP определение страны и кэш стран;
    парсеры ключей оставить. Источник (3 подписки, зеркала githack→github) — как есть.
- **geoip**
  - `internal/geoip/` (geoip.go + embedded `dbip-country-lite.mmdb` ~8 МБ) —
    **удалить целиком**, если после задачи никто не импортирует. Убрать `NOTICE.md`
    в части DB-IP, если она была только про geoip.
- **singbox** — генерация пула из состояния БД не завязана на страну (пул есть пул).
  Проверить, что тип/тег/`urltest` не полагаются на `Country`.
- **api** — `internal/api/tunnels.go`: убрать `Country` из `tunnelResponse` (или
  оставить пустым). Формулировки про «страновые пулы» → «общий пул».
- **ui** — `ui/dist/js/screens/tunnels.js`: убрать раздел «Дефолтные туннели по
  странам» и признак `isCountryPool`; встроенный пул рисуется как один туннель в общем
  списке. `ui/dist/js/screens/settings.js` не трогаем. Убрать `poolCountryLabel` и
  связанное (см. лог ui #161, #171, #178).

## Обязательно

- **Инварианты (AGENTS.md):** конфиг sing-box генерируется целиком, `sing-box check`
  до применения; правило с недоступным туннелем — `reject` (ADR 0013); пул заводится
  выключенным; исходящие туннели userspace; `CGO_ENABLED=0`.
- **ADR 0018** «заменяет 0017»: единый общий пул, источник igareck по всем странам,
  привязка клиентов правилами по пирам, geo-IP убран. Обновить
  `docs/decisions/README.md`; 0017 → статус «заменено (0018)».
- **Документация ведёт код:** сначала docs (AGENTS.md pitch, docs/02-data-model.md,
  docs/05-api.md), затем код.
- **Логи слоёв** store/lists/singbox/api/ui: запись по схеме, ≤400 байт (кириллица
  вдвое — см. память `ci-lint-and-log-budget`). Инварианты store/lists обновить.
- **Ребейз запрещён** (AGENTS.md). Работа в этом воркtree, PR наружу, мержит оркестратор.

## Критерии приёмки

См. issue #181. Кратко: один встроенный пул вместо 7; наполняется всеми ключами
igareck; ротация urltest; миграция сворачивает 7→1 и отвязывает правила по ADR 0013;
geo-IP убран; ADR 0018; доки и логи; `make build`/`make test` и CI зелёные; проверено
на стенде.

## Проверка на стенде (делает оркестратор после мержа)

Стенд 186.246.29.11 (Debian 13). Включить общий пул, убедиться: наполняется ключами
разных стран (один пул, смешанные протоколы допустимы), `urltest` держит живой и
ротирует; правило, навешенное на конкретного пира, уходит в пул, остальные пиры — мимо;
после апгрейда с версии со странами миграция свернула 7→1 без утечки правил.
