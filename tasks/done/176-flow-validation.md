## TLDR
Ключ из подписки с неподдерживаемым `flow` (`xtls-rprx-vision-udp443`) роняет
весь конфиг sing-box, и 5 из 7 страновых пулов не применяются. Валидировать
`flow` при разборе proxy-URL и отбраковывать сервер с неизвестным значением.

## Goal
Один битый ключ из чужой подписки не отравляет весь конфиг: неизвестный `flow`
отсекается на разборе, остальные серверы применяются.

## Domains touched
- [singbox](../context/singbox/index.md) — разбор proxy-URL, валидация flow

## Decisions
- 2026-08-17: `flow` принимает только `""` и `xtls-rprx-vision`; иное — отказ разбора (ErrParse), как уже сделано для `encryption`.
- 2026-08-17: не нормализовать `-udp443` → `vision` — sing-box значение не держит, ключ не соединится, честнее выбросить.

## Acceptance criteria
- [ ] Ключ с неизвестным `flow` (в т.ч. `xtls-rprx-vision-udp443`) отбраковывается разбором
- [ ] `flow=""` и `flow=xtls-rprx-vision` разбираются как прежде
- [ ] Один битый ключ в пуле не мешает применению остальных (конфиг проходит `sing-box check`)
- [ ] Проверено на стенде: применяются все 7 включённых пулов
