## TLDR
Оповещать некуда: канала не существует. Заводим отправку в телеграм — токен,
chat_id, блок в модалке настроек и кнопку «отправить тестовое», — не привязывая
её пока ни к одному событию, чтобы транспорт проверялся отдельно от логики.

## Goal
Сообщение из демона доезжает в указанный телеграм-чат по нажатию кнопки.

## Domains touched
- [api](../context/api/) — сохранение настроек, `POST /api/notify/test`, пакет `internal/notify`
- [store](../context/store/) — токен, chat_id, флаг включения
- [ui](../context/ui/) — блок уведомлений в модалке настроек

## Decisions
- 2026-07-27 — бота заводит пользователь в @BotFather, демон хранит токен и
  chat_id. Своей регистрации быть не может: бот принадлежит пользователю.
- 2026-07-27 — выключено по умолчанию. Пока уведомления не включили и токен не
  сохранили, исходящих запросов к api.telegram.org нет — тот же принцип, по
  которому заводится выключенным туннель-пул.
- 2026-07-27 — один транспорт, без интерфейса «методов нотификации». Абстракция
  под второй транспорт до появления второго — догадка о том, каким он будет.
- 2026-07-27 — отдельного экрана нет: инвариант слоя ui держит четыре экрана, а
  настройки живут модалкой (`ui/dist/js/app.js:304`).
- 2026-07-27 — `internal/notify` не ложится ни в один из семи объявленных слоёв.
  Ведём его в памяти слоя api до появления второго потребителя; новый слой ради
  одного пакета не заводим.

## Acceptance criteria
- [ ] «Отправить тестовое» доставляет сообщение в указанный чат
- [ ] Токен не возвращается в ответах API ни в каком виде
- [ ] С выключенными уведомлениями запросов к api.telegram.org нет
- [ ] Неверный токен даёт внятную ошибку на русском, а не молчание
- [ ] Отправка не блокирует HTTP-обработчик дольше внятного таймаута
