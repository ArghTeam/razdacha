## TLDR
Драйвер источника igareck + переделка обновления пулов на fetch-once-partition:
один обход источника раскладывается по 7 странам через geoip. Часть #167.

## Goal
Включённый страновой пул наполняется только серверами своей страны; общий
источник обходится один раз на все пулы, страна — офлайн geoip по адресу.

## Domains touched
- [lists](../context/lists/index.md) — драйвер igareck (3 подписки, зеркала), geoip-раскладка, fetch-once-partition в Refresh

## Decisions
- 2026-08-17 (ADR 0017): источник igareck, зеркало CDN основным (raw.githack.com), raw.githubusercontent fallback.
- 2026-08-17: страна — geoip по адресу сервера (домен резолвится), не метка.
- 2026-08-17: один обход общего источника раскладывается по включённым страновым пулам; выключенные пропускаются.

## Acceptance criteria
- [ ] Включённый пул наполняется только серверами своей страны (проверка на стенде по exit-IP)
