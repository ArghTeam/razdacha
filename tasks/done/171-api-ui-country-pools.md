## TLDR
Показать 7 страновых пулов в панели вместо строки «Бесплатные ключи»; снять из
API допущение «пул в системе один». Часть #167.

## Goal
Пользователь видит 7 страновых пулов с флагом, статусом и тумблером; включает/
выключает и обновляет каждый; свои туннели добавляет как раньше.

## Domains touched
- [api](../context/api/index.md) — снять «пул один», отдавать набор страновых пулов
- [ui](../context/ui/index.md) — 7 страновых пулов на экране туннелей

## Decisions
- 2026-08-17 (ADR 0017): страновые пулы builtin — через API не создаются/не удаляются; включение/выключение и «обновить» доступны у каждого.
- 2026-08-17: имя пула (флаг + страна) уже приходит из store (PoolName) — UI его показывает как есть.

## Acceptance criteria
- [ ] Панель показывает 7 страновых пулов с флагом, статусом и тумблером
- [ ] Включение/выключение и «обновить» работают у каждого пула
- [ ] Создать/удалить страновой пул через API нельзя (builtin)
- [ ] В редакторе правил страновые пулы выбираются как туннели
