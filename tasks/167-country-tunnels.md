## TLDR
Заменить единственный бесплатный пул на 7 захардкоженных дефолтных туннелей по
странам (NL, DE, US, FR, GB, FI, KZ). Каждый — страновой срез общего источника
igareck с ротацией urltest внутри. Страна — офлайн geo-IP по адресу сервера.

## Goal
Пользователь выбирает выход по стране; внутри страны трафик сам держится живого
и быстрого сервера, состав обновляется по расписанию.

## Domains touched
- [store](../context/store/) — миграция: колонка country, удаление старого пула, EnsureBuiltinCountryPools
- [lists](../context/lists/) — драйвер igareck (3 подписки, зеркала), geoip-раскладка, fetch-once-partition в Refresh; сюда же новый internal/geoip
- [singbox](../context/singbox/) — проверить Parse на trojan/vmess из igareck; механика пула не меняется
- [api](../context/api/) — снять допущение «пул один», отдавать 7 страновых пулов
- [ui](../context/ui/) — 7 страновых пулов вместо строки «Бесплатные ключи», флаг+статус+тумблер
- [packaging](../context/packaging/) — embed mmdb (+~4МБ), атрибуция DB-IP Lite (CC-BY-4.0)

## Decisions
- 2026-08-17: 7 стран, хардкод — NL, DE, US, FR, GB, FI, KZ (порог ≥8 уникальных exit-IP по разведке igareck; RU и хвост отброшены).
- 2026-08-17: страна — офлайн geo-IP (DB-IP Country Lite, embed, чистый Go maxminddb), не метка источника. Заменяет пункт ADR 0015 о единственном встроенном пуле — заводится новый ADR, уточняющий ADR 0010.
- 2026-08-17: источник igareck, зеркало CDN основным, raw.githubusercontent fallback.
- 2026-08-17: старый builtin-пул удаляется миграцией; правила-ссылки отвязываются (reject/выключение с логом).
- 2026-08-17: все пулы выключены по умолчанию; крон не заводится — переиспользуется PoolManager (12ч).

## Acceptance criteria
- [ ] Свежая установка: 7 выключенных страновых пулов, наружу за ключами не ходят
- [ ] Включённый пул наполняется только серверами своей страны (проверка на стенде по exit-IP)
- [ ] Один обход источника наполняет все включённые пулы (один fetch в логе)
- [ ] После апгрейда старого пула нет, правила на него не висят битой ссылкой
- [ ] Пустой пул страны → правило reject (ADR 0013)
- [ ] Атрибуция DB-IP Lite в бинарнике/доках
