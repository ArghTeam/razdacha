## TLDR
WARP добавляется кнопкой: демон регистрирует бесплатный ключ у Cloudflare и заводит
обычный wireguard-туннель. Ходит наружу только по явному действию, как туннель-пул.

## Goal
Убрать ручной wgcf-конфиг из пути «хочу гнать часть доменов через WARP».

## Domains touched
- [singbox](../context/singbox/) — регистрация ключа и сборка endpoint
- [store](../context/store/) — новый source туннеля, хранение client ID
- [api](../context/api/) — ручка добавления WARP
- [ui](../context/ui/) — кнопка на экране туннелей

## Decisions
- 2026-07-27 — WARP это `source`, а не новый `TunnelType`: протокол остаётся wireguard,
  меняется только откуда взялись ключи. Иначе пришлось бы дублировать всю ветку
  генерации ради того же endpoint.
- 2026-07-27 — наружу только по явному действию, повторяя контракт ADR 0010:
  установка не должна ходить в Cloudflare сама по себе.
- 2026-07-27 — зависимости от #98 нет: стенд показал, что WARP работает и **без** поля
  `reserved` — тот же внешний адрес 104.28.219.140 и та же задержка, что с ним. Поле
  разбирается ради совместимости с конфигами, которые его несут, не более.
- 2026-07-27 — [ADR 0012](../docs/decisions/0012-tunnel-chain-detour.md) опирается на эту
  задачу: `source = "warp"` — признак второго звена цепи «туннель → WARP». Значит source
  проставляют два пути, и оба входят сюда: кнопка регистрации и распознавание вставленного
  `.conf` по хосту endpoint на `cloudflareclient.com`.
- 2026-07-27 — регистрация делается запросом к API Cloudflare (`api.cloudflareclient.com`),
  без внешних бинарников: `wgcf` в цепочку демона не тянем, как не тянем `wg` и `nft`.

## Acceptance criteria
- [ ] кнопка заводит рабочий WARP-туннель без ручного `.conf`
- [ ] до нажатия исходящих запросов к Cloudflare нет
- [ ] ключ переживает перезапуск, повторное нажатие не плодит туннели
- [ ] ошибка регистрации показывается на русском, туннель не создаётся
- [ ] вставленный вручную `.conf` с endpoint на `cloudflareclient.com` получает
      `source = "warp"` сам, без кнопки
- [ ] на стенде: правило со списком уходит в WARP, внешний адрес — Cloudflare
