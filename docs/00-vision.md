# Vision

## Проблема

Существующие решения делят пользователей на две неудобные группы.

**Podkop и подобное** решают задачу селективной маршрутизации отлично, но требуют
роутера с OpenWrt. Работает только дома, только для устройств в локальной сети, только
для тех, кто готов перепрошить роутер. Телефон вне дома не защищён.

**Обычные VPN** (свой WireGuard, wg-easy, коммерческие сервисы) работают везде и на
любом устройстве, но гонят **весь** трафик через один выход. Следствия: банки и госуслуги
видят зарубежный IP и блокируют, локальные сервисы работают медленно, весь трафик идёт
через один канал с его лимитами, а сам туннель проще заблокировать по объёму.

**Панели вроде 3x-ui / marzban** умеют правила маршрутизации, но они заточены на
*раздачу* vless-подписок клиентам, а не на селективный *исход*. Интерфейс рассчитан на
администратора, который вручную составляет правила, а не на человека, который хочет
поставить галочку «YouTube через туннель».

## Что делает razdacha

Ставится на любой VPS или домашний сервер. После установки:

1. Поднят WireGuard-сервер, первый клиентский конфиг напечатан QR-кодом в терминале.
2. Клиент (телефон/ноутбук) отправляет **весь** трафик на сервер — стандартным
   WireGuard-клиентом, без дополнительного ПО.
3. Сервер разбирает трафик: выбранные списки ресурсов уходят в настроенные туннели,
   всё остальное — напрямую с IP сервера.
4. В веб-интерфейсе: добавить туннель (вставить `vless://…` или `.conf` WireGuard),
   отметить галочками списки, скачать конфиг клиенту.

Селективность работает **на сервере**, поэтому клиент остаётся тривиальным и одинаковым
на всех платформах — включая те, где ничего кроме WireGuard не поставить.

## Целевой пользователь

Человек, который уже умеет арендовать VPS и выполнить `curl … | sh`, но не хочет
разбираться в nftables, sing-box JSON и таблицах маршрутизации. Настраивает для себя
и семьи — от 1 до ~20 клиентов.

Не enterprise, не многопользовательский сервис с биллингом, не хостинг для перепродажи.

## Отличия от существующих решений

| | клиенты без ПО | селективная маршрутизация | курируемые списки | несколько туннелей | простой UI |
|---|---|---|---|---|---|
| **razdacha** | ✅ wg | ✅ | ✅ | ✅ | ✅ |
| Podkop | ✅ (только LAN) | ✅ | ✅ | ✅ | средне |
| wg-easy | ✅ wg | ❌ | ❌ | ❌ | ✅ |
| 3x-ui / marzban | ❌ vless-клиент | частично | ❌ | ✅ | ❌ |
| Hiddify / clash-verge | ❌ свой клиент | ✅ | частично | ✅ | ✅ |
| AmneziaVPN | ✅ wg/awg | ❌ | ❌ | ❌ | ✅ |

Ниша — пересечение «клиент ничего не ставит» и «маршрутизация селективная по готовым
спискам». Его сейчас не занимает никто.

## Ключевые продуктовые принципы

1. **Клиент остаётся глупым.** Любая функция, требующая специального клиентского ПО,
   отклоняется. Всё умное — на сервере.
2. **Четыре экрана, не больше.** Клиенты, Туннели, Правила, Диагностика. Каждая новая
   настройка должна вытеснить существующую или быть отклонена.
3. **Разумные дефолты вместо опций.** MTU, DNS-стратегия, keepalive, диапазон FakeIP —
   не спрашиваем, ставим правильно. См. [ADR 0004](decisions/0004-client-mtu-1280.md).
4. **Работает после установки, без настройки.** Установщик доводит до состояния
   «первый клиент подключён и ходит в интернет».
5. **Не ломает сервер.** Все изменения системного состояния обратимы, удаление
   восстанавливает исходную конфигурацию.

## Non-goals

- Десктопное приложение и per-app маршрутизация — это другой продукт
  (см. [ADR 0001](decisions/0001-gateway-not-desktop.md)).
- Биллинг, лимиты трафика, многопользовательский доступ к панели.
- Обфускация и обход DPI на стороне клиент↔сервер. WireGuard детектируется DPI; кому
  нужна маскировка входящего канала — это отдельная задача (AmneziaWG, vless-инбаунд),
  вне первых версий.
- IPv6 для клиентов — сознательно отключён
  ([ADR 0005](decisions/0005-ipv6-off-via-dns-strategy.md)).
- Поддержка OpenWrt. Там уже есть Podkop, дублировать незачем.
